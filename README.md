# 🌌 Solar System – Planet Picker Animation

Explore the wonders of our solar system with this interactive **Solar System Planet Picker Animation**! 🚀

This project features an animated solar system where users can select different planets and explore their details through an engaging visual experience. It combines creative animations, interactive elements, and a space-inspired design to make learning about planets fun and interesting.

## ✨ Features

- 🌍 **Interactive Planet Selection** – Select different planets and explore them.
- 🪐 **Smooth Animations** – Enjoy visually appealing planetary animations.
- ☀️ **Solar System Visualization** – Explore the planets in a space-themed environment.
- 📚 **Planet Information** – Discover interesting facts and details about each planet.
- 🎨 **Modern UI Design** – Clean, attractive, and user-friendly interface.
- 📱 **Responsive Design** – Designed to provide a good experience across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/sindhu6635/solar-system-planet-picker.git
```

**2. Navigate to the project folder**

```bash
cd solar-system-planet-picker
```

**3. Run the project**

Open the `index.html` file in your browser.
